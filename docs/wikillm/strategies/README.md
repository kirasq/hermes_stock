## ⚡ 策略分类

### 趋势跟踪（Trend Following）
**核心思想**：跟着大趋势走，不猜顶不抄底

**入场条件**：
- 价格在 MA60 上方（上升趋势）
- MA5 > MA20（短期均线金叉）
- 成交量放大

**出场条件**：
- 止损：-8%（从 rules.json 读取）
- 止盈：+20%（分批兑现）
- MA5 < MA20（均线死叉）

### 均值回归（Mean Reversion）
**核心思想**：价格会回归到均值附近

**入场条件**：
- RSI < 30（超卖）
- 价格跌破布林带下轨
- 成交量萎缩（抛压衰竭）

**出场条件**：
- 回到布林带中轨
- RSI > 50

### 突破策略（Breakout）
**核心思想**：价格突破关键位置后会有延续性

**入场条件**：
- 价格放量突破近期高点（前 N 日高点）
- 成交量明显放大（> 5日均量的 1.5 倍）
- 集合竞价放量（> 昨日竞价量的 2 倍）

**出场条件**：
- 止损：跌破突破位置价格 -1%
- 止盈：突破后涨 10% 止盈一半，剩余跟踪

### 网格交易（Grid Trading）
**核心思想**：在震荡市中低买高卖

**操作方式**：
- 设定价格区间（支撑位~阻力位）
- 每隔固定价差挂一笔买入/卖出

**适合条件**：
- 震荡市（RSI 在 30~70 之间）
- 流动性好的股票

| 策略 | 适合市况 | 最大回撤 | 胜率 | 频率 |
|------|---------|---------|------|------|
| 趋势跟踪 | 单边牛/熊市 | 中 | ~40% | 低 |
| 均值回归 | 震荡市 | 低 | ~60% | 中 |
| 突破策略 | 所有（需信号确认） | 高 | ~35% | 低 |
| 网格交易 | 震荡市 | 低 | ~70% | 高 |

## 🚫 常见失败模式

| 失败模式 | 原因 | 对策 |
|----------|------|------|
| 趋势末期买顶 | 追高在高点 | 用成交量确认趋势强度 |
| 震荡市被左右打脸 | 策略不适合当前市况 | 识别市况切换策略 |
| 过早止盈 | 不敢让利润奔跑 | 分批止盈 + 抬止损到成本价 |
| 不止损扛单 | 害怕承认错误 | 硬止损，无商量 |
