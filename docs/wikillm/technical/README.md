## 📊 技术指标

### MA（移动平均线）
- **SMA（简单移动平均）**：N 日收盘价的平均值
- **EMA（指数移动平均）**：近期价格权重更大
- **用法**：
  - 金叉：短周期 MA 上穿长周期 MA → 买入信号
  - 死叉：短周期 MA 下穿长周期 MA → 卖出信号
  - 支撑/阻力：价格在 MA 上方 → 支撑；下方 → 阻力

### MACD（指数平滑异同移动平均线）
- **DIF**：快线（EMA12 - EMA26）
- **DEA**：慢线（DIF 的 9 日 EMA）
- **用法**：
  - DIF 上穿 DEA → 金叉，买入信号
  - DIF 下穿 DEA → 死叉，卖出信号
  - 柱状图（DIF - DEA）放大 → 趋势加强

### RSI（相对强弱指标）
- **范围**：0~100
- **超买**：RSI > 70（警惕回调）
- **超卖**：RSI < 30（警惕反弹）
- **背离**：价格创新高但 RSI 不创新高 → 趋势可能反转

### 布林带（Bollinger Bands）
- **中轨**：20 日 SMA
- **上轨/下轨**：中轨 ± 2 倍标准差
- **用法**：
  - 价格触及上轨 → 可能回调
  - 价格触及下轨 → 可能反弹
  - 带宽收窄 → 即将变盘（波动率降低）

## 📈 K 线形态

### 单根 K 线
- **大阳线**：实体长、无上下影线 → 强势上涨
- **大阴线**：实体长、无上下影线 → 强势下跌
- **十字星**：开盘价≈收盘价 → 转折信号
- **锤子线**：下影线长、实体小 → 底部反转信号
- **流星线**：上影线长、实体小 → 顶部反转信号

### 组合形态
- **早晨之星**：阴线 + 十字星 + 阳线 → 底部反转
- **黄昏之星**：阳线 + 十字星 + 阴线 → 顶部反转
- **红三兵**：三根连续阳线 → 持续上涨
- **黑三兵**：三根连续阴线 → 持续下跌

## 🔄 量价关系

| 价量组合 | 含义 |
|------------|------|
| 价升量增 | 上涨有量支撑，趋势健康 |
| 价升量缩 | 上涨无量，警惕假突破 |
| 价跌量增 | 下跌带量，抛压严重 |
| 价跌量缩 | 下跌无量，可能止跌 |

## ⚡ 支撑与阻力

- **支撑位**：历史上多次止跌反弹的价格区域
- **阻力位**：历史上多次止涨回落的价格区域
- **突破阻力**：放量突破 → 新上涨空间打开
- **跌破支撑**：放量跌破 → 新下跌空间打开
