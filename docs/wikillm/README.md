# WikiLLM — 股票交易知识库

> ⚠️ **重要声明**：本知识库信息来自互联网，未经实盘验证，仅供借鉴参考，非金科玉律！请结合自己的交易实践进行验证。

基于 Andrej Karpathy（前 Tesla AI 总监、OpenAI 创始成员）提出的 LLM Wiki 理念，构建股票交易领域的结构化知识库。

## 🎯 知识库结构

| 模块 | 目录 | 内容 |
|------|------|------|
| 📈 技术分析 | `wikillm/technical/` | K线形态、量价关系、技术指标 |
| 🏦 基本面分析 | `wikillm/fundamental/` | 财报解读、估值体系、杜邦分析 |
| 🧠 交易心理学 | `wikillm/psychology/` | 恐惧贪婪、纪律执行、认知偏误 |
| 🛡️ 风险管理 | `wikillm/risk-management/` | 仓位管理、止损策略、最大回撤 |
| ⚡ 交易策略 | `wikillm/strategies/` | 趋势跟踪、均值回归、突破策略 |
| ⚙️ 市场机制 | `wikillm/market-mechanism/` | 集合竞价、龙虎榜、板块轮动 |
| 📊 量化交易 | `wikillm/quantitative/` | 因子模型、回测方法论、夏普比率 |

## 📚 使用方式

1. **浏览**：访问 GitHub Pages（自动部署）
2. **搜索**：使用 GitHub 搜索功能，搜索关键词
3. **贡献**：每个 markdown 文件都是一篇知识条目，自由编辑

## 🔄 更新机制

- trader-strategy 每日消费互联网信息（mx-search）
- 筛选有价值的内容，整理后写入 WikiLLM
- 自动 push 到 GitHub，触发 Pages 更新
