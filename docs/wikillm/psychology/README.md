## 🧠 核心认知

### 恐惧与贪婪
- **恐惧**：亏损时不敢止损，导致小亏变大亏
- **贪婪**：盈利时不愿止盈，导致利润回吐
- **对策**：用规则（stoploss/takeprofit）对抗情绪

### 损失厌恶（Loss Aversion）
- 亏 100 元的痛苦 > 赚 100 元的快乐
- 导致：不止损、摊薄成本（越跌越买）
- **对策**：预设止损线，触及即卖，无例外

### 确认偏误（Confirmation Bias）
- 只关注支持自己观点的信息
- 忽视反面信号
- **对策**：强制列出 3 个反对自己交易的理由

## 🎯 纪律执行

### 止损纪律（最重要！）
```
止损触发 = 立即卖出
无商量、无二次确认、无例外
```
- 这是专业交易的第一法则
- 自进化系统可以调整止损参数，但**不能放宽止损**
- 止损是硬约束，不是软建议

### 让利润奔跑
- 止盈后剩余仓位抬止损到成本价
- 这样即使价格回调也不会亏损
- 分批兑现利润（先卖 50%），剩余继续跟踪

## 🚫 常见认知偏误

| 偏误 | 表现 | 对策 |
|------|------|------|
| 锚定效应 | 以买入价为参考，不愿止损 | 用技术位/百分比止损 |
| 赌徒谬误 | 连跌后认为必涨 | 趋势为王，不猜底 |
| FOMO | 追高买入 | 设定入场条件，不满足不买 |
| 处置效应 | 过早卖出盈利股，长期持有亏损股 | 反其道而行 |
| 后见之明 | 事后觉得当时应该知道 | 记录当时的真实想法 |

## 💪 心态管理

### 日内交易心态
- 每天开盘前：清空昨天情绪
- 连续亏损 3 笔 → 暂停交易，冷静复盘
- 连续盈利 → 不能得意忘形，纪律不能松懈

### 长期交易心态
- 关注过程（执行纪律），而非结果（盈亏）
- 一周回顾：胜率、盈亏比、止损执行率
- 一个月回顾：策略是否需要优化
