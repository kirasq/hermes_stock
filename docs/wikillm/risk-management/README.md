## 🛡️ 仓位管理

### 核心原则
- 单票最大仓位：不超过总资产的 30%（可自进化调整）
- 总仓位：不超过 80%，留 20% 现金应对极端情况
- 每日最大亏损：不超过总资产的 5%（触发即停）

### 仓位计算公式
```python
# 基于凯利公式的简化版
# f* = (bp - q) / b
# b = 赔率（平均盈利 / 平均亏损）
# p = 胜率
# q = 败率（1 - p）

# 本系统使用的简化仓位管理：
position_size = min(
    max_position_pct,        # 从 rules.json 读取
    avail_capital * 0.8      # 不超过可用资金的 80%
)
```

## 止损策略

### 三种止损方式
1. **百分比止损**（当前系统使用）：
   - 读取 `/opt/data/trading/rules.json` 中的 stop_loss_pct
   - 默认 -8%，触及即卖
2. **技术位止损**（参考）：
   - 支撑位下方 1-2 格
   - 如突破支撑则卖
3. **时间止损**（参考）：
   - 买入后 N 天不涨 → 卖出

### 自进化止损
- 系统通过回测自动调整止损参数
- 但止损纪律永远不可放宽
- 收紧止损可以（如 -8% → -7%）
- 放宽止损需要人工确认（如 -8% → -10%）

## 最大回撤控制

### 回撤计算
```
最大回撤（MDD）= max(历史最高点 - 当前点) / 历史最高点 * 100%
```

### 回撤应对
| 回撤幅度 | 应对措施 |
|-----------|---------|
| < 5% | 正常交易 |
| 5-10% | 降低仓位到 50% |
| 10-15% | 只卖不买 |
| > 15% | 清仓休息，全面复盘 |

## 凯利公式

### 标准凯利
```
f* = (bp - q) / b

f* = 最优仓位比例
b  = 赔率（平均盈利/平均亏损的绝对值）
p  = 胜率（%）
q  = 1 - p
```

### 半凯利（推荐）
```
f_half = f* / 2
```
半凯利更保守，降低了破产风险

## 📊 风险指标

| 指标 | 含义 | 公式 |
|------|------|------|
| 夏普比率 | 单位风险的超额收益 | (回报率 - 无风险率) / 标准差 |
| 索提诺比率 | 只考虑下行风险 | 同夏普但分母用下行标准差 |
| 最大回撤 | 最坏情况 | 见上 |
| Calmar 比率 | 年化收益 / 最大回撤 | 越高越好 |
| 盈亏比 | 平均盈利 / 平均亏损 | > 1.5 才可持续 |
